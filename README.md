# SATN: Semantic-Aware Transformer Network
Abstractive text summarization + automated knowledge extraction. Upload a PDF/DOCX/TXT and get a summary,
key sentences, entities, key phrases and relations. No API keys required.

## Run locally
pip install -r requirements.txt
streamlit run app.py

## Deploy
Streamlit Community Cloud -> New app -> select this repo -> main file: app.py (Python 3.11).
